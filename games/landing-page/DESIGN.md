# Leviathan Design System

## Art Direction
- **Background**: Deep void with subtle purple/pink nebula glows
- **Typography**: Outfit (headings), Inter (body) — bold, editorial, cinematic
- **Colors**: Black/white base with violet (#7c3aed) accent and pink (#ec4899) secondary
- **Layout**: Layered compositions, generous whitespace, cinematic sections
- **Animation**: Float, pulse-glow, scroll reveals, smooth Lenis scrolling

## Component Principles
1. Artwork is the hero — glass panels support, never compete
2. Minimalist UI — only essential buttons visible
3. Strong visual hierarchy — font-black headings, muted body text
4. Smooth interactions — GSAP scroll triggers, hover scales, glows
5. Brand identity — every element feels like the Leviathan universe

## Color Usage
- `--levi-accent`: primary actions, glows, badges
- `--levi-accent-glow`: subtle outer glows on cards/buttons
- `text-gradient`: headline text treatment
- `glass-panel`: semi-transparent dark surfaces with backdrop blur
